One letter for the day: **K** — for *knackered*, utterly exhausted at the end of a day that has wrung you out completely. Vivid and specific (flat on the sofa, shoes still on, too spent to move), funny in the blunt slangy way it lands at once, and true to a real day. K is not the obvious pick: the rules' own examples (A for amazing, F for Friday-feeling, Z for zero sleep) will be crowded, while K's most likely day-word is exactly this one sharp word.

## Run it

```sh
node main.ts
```

It validates the letter against the bounty gate (exactly one capital letter A–Z, the initial of the hidden word *knackered*) and writes it to `/output/entry.txt`, reading the file back — as text and as raw bytes — to prove the round trip.
